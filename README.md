# 🌿 Plant Website

A simple, responsive plant website built with **HTML** and **Tailwind CSS**. It showcases plants, plant care tips, and related content in a clean, modern layout.

## 📌 Features

- Fully responsive design for mobile, tablet, and desktop
- Clean and modern UI using Tailwind CSS utility classes
- Sections for plant listings, plant care tips, and about/contact info
- Easy to customize colors, spacing, and layout via Tailwind classes
- No build step required (uses Tailwind via CDN)

## 🛠️ Tech Stack

- **HTML5** – Structure and content
- **Tailwind CSS** – Styling and responsive design
- **Tailwind Play CDN** – Quick setup without a build process

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, etc.)
- No Node.js or npm required (CDN-based setup)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/plant-website.git
   cd plant-website
   ```

2. Open `index.html` in your browser:
   - Double-click the file, or
   - Use a live server extension (e.g., Live Server in VS Code)
